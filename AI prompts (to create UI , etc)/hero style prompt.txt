# HERO DESIGN SYSTEM

Every Hero should feel like part of the same RAMIS design system.

Do NOT simply change the background color.

The Hero should have several coordinated visual layers:

### 1. Premium Background

Use a sophisticated combination of:

* Dark green gradient
* RAMIS primary green
* Very subtle gold radial glow
* Very subtle turquoise/green atmospheric glow

Preferred direction:

```css
background:
    radial-gradient(
        circle at 88% 15%,
        rgba(255,206,58,0.12),
        transparent 29%
    ),
    radial-gradient(
        circle at 8% 85%,
        rgba(0,180,165,0.17),
        transparent 34%
    ),
    linear-gradient(
        135deg,
        #003F3C 0%,
        #006660 52%,
        #00332F 100%
    );
```

Do not overuse gradients.

The background must remain elegant and premium.

---

# 2. Hero Shape

The main Hero should generally have:

* Rounded bottom corners
* Approximately `30px` desktop radius
* Approximately `22px` mobile radius

Example:

```css
border-radius: 0 0 30px 30px;
```

Do not force rounded top corners unless the existing page structure requires them.

---

# 3. Background Glow

Add subtle decorative light effects using pseudo-elements.

Use:

* `::before`
* `::after`

for atmospheric lighting.

The effects must be:

* subtle
* blurred
* non-interactive
* behind the content
* visually sophisticated

Never let pseudo-elements interfere with text, links, buttons, or images.

Use:

```css
pointer-events: none;
```

and appropriate `z-index`.

---

# 4. Typography

Hero titles must feel strong and premium.

For Persian titles:

* White text
* Heavy/bold weight
* Large responsive typography
* Tight but natural letter spacing
* Strong line-height
* Subtle text shadow if appropriate

Preferred:

```css
font-size: clamp(32px, 4vw, 46px);
font-weight: 900;
line-height: 1.4;
color: #FFFFFF !important;
```

Do not make typography unnecessarily huge.

The title should remain elegant on desktop and mobile.

---

# 5. Gold Accent Line

Every Hero title should have a small gold decorative line underneath.

Use:

```css
content: "";
display: block;
width: 55px;
height: 4px;
margin-top: 14px;
background: #FFCE3A;
border-radius: 20px;
```

The line may slightly expand on hover.

Example:

```css
width: 82px;
```

The animation must be subtle.

On mobile, center the line if the Hero text is centered.

---

# 6. Description

Hero descriptions should be:

* White with reduced opacity
* Comfortable to read
* Medium/small size
* High line-height
* Limited in width
* RTL-friendly

Preferred visual style:

```css
color: rgba(255,255,255,0.74);
font-size: 15px;
line-height: 2.15;
```

On hover, it may become slightly brighter, but avoid unnecessary animation.

---

# 7. Image Design

If the Hero contains an image:

The image should NOT look like a plain Elementor image widget.

Create a premium visual treatment.

The image should generally have:

* Rounded corners
* Soft border
* Deep shadow
* Subtle gold frame/glow
* Slight initial rotation on desktop
* Smooth hover animation

Preferred:

```css
border-radius: 20px;

border:
    1px solid rgba(255,255,255,0.15);

box-shadow:
    0 25px 55px rgba(0,0,0,0.28);
```

The image container can initially have:

```css
transform: rotate(2deg);
```

On hover:

```css
transform:
    rotate(0deg)
    translateY(-7px);
```

Do NOT exaggerate the rotation.

---

# 8. Premium Image Frame

If appropriate, create a subtle frame around the image using the image container's `::before`.

Use:

* transparent gold border
* subtle translucent gradient
* soft glow

Example direction:

```css
border: 1px solid rgba(255,206,58,0.30);
```

On hover, the border can become slightly brighter.

The frame must remain subtle.

---

# 9. Decorative Elements

You may add very small decorative elements such as:

* Gold dot
* Soft gold glow
* Thin gold line
* Subtle light orb

However:

**Do not overcrowd the Hero.**

The design should feel like a premium commercial website, not a flashy gaming interface.

---

# 10. Hover Animations

Animations should feel smooth and expensive.

Preferred timing:

```css
transition:
    transform .4s cubic-bezier(.2,.8,.2,1),
    box-shadow .4s ease,
    border-color .4s ease;
```

Good hover effects include:

* Image moving slightly upward
* Image scaling slightly
* Gold line expanding
* Gold glow becoming slightly stronger
* SVG/icon scaling slightly

Avoid:

* aggressive rotations
* bouncing
* excessive scaling
* flashing
* constant animations
* distracting effects

---

# 11. Elementor Compatibility

The CSS must work inside:

**Elementor → Container → Advanced → Custom CSS**

Therefore:

* Use `selector` for the root container whenever possible.
* Scope all styles under `selector`.
* Avoid global selectors.
* Avoid styling unrelated page elements.
* Do not use `body`, `html`, or generic global selectors unless absolutely necessary.

Example:

```css
selector {
    ...
}

selector .elementor-element-XXXXXXX {
    ...
}
```

This is extremely important because multiple Heroes may exist across different pages.

---

# 12. Use Real Elementor IDs

When I send markup such as:

```html
<div class="elementor-element elementor-element-f7685c ...">
```

the root container is:

```text
f7685c
```

If a child is:

```html
<div class="elementor-element elementor-element-443b89b ...">
```

use:

```css
selector .elementor-element-443b89b
```

Do NOT invent IDs such as:

```text
.elementor-element-123456
```

Only use IDs that actually exist in the markup I provide.

# 14. Responsive Design

Every Hero MUST include responsive styling.

At minimum provide:

### Desktop

Above `1024px`

### Tablet

`768px – 1024px`

### Mobile

Below `767px`

Mobile should:

* Reduce padding
* Reduce title size
* Reduce image size
* Remove unnecessary rotation
* Center text when appropriate
* Reduce decorative effects
* Maintain comfortable spacing
* Prevent horizontal overflow

Never allow:

```text
horizontal scrolling
content overflow
broken images
text clipping
```

---

# 15. Accessibility / Performance

Do not use unnecessary animations.

Respect:

```css
@media (prefers-reduced-motion: reduce)
```

Disable or minimize transitions for users who prefer reduced motion.

Do not use heavy filters or expensive effects unnecessarily.

Avoid JavaScript.

The solution must be pure CSS unless there is a strong reason otherwise.
